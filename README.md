# 🚀 Ventrya — Global Solution 2026/2

**FIAP | CitizenTech | Azure DevOps Boards**

## 📌 Sobre o projeto

A **Ventrya** é uma plataforma voltada à empregabilidade jovem, desenvolvida como parte da Global Solution 2026/2 da FIAP.

A solução busca ajudar jovens de 16 a 24 anos a adquirir experiências práticas antes de ingressarem no mercado de trabalho, por meio de desafios propostos por organizações, avaliações com inteligência artificial, geração automática de portfólio e entrevistas simuladas.

## 🎯 Objetivo

Reduzir as barreiras enfrentadas por jovens que buscam sua primeira oportunidade profissional, oferecendo recursos para desenvolver competências, receber feedbacks personalizados e construir experiências que possam ser apresentadas em processos seletivos.

## 📋 Gerenciamento do projeto

O planejamento e o acompanhamento das atividades foram realizados no **Azure DevOps Boards**, utilizando uma estrutura hierárquica composta por:

- **Epics:** principais módulos do projeto.
- **Features:** funcionalidades de cada módulo.
- **Product Backlog Items (PBIs):** requisitos e histórias de usuário, com descrições e critérios de aceite.
- **Tasks:** atividades técnicas necessárias para implementar as funcionalidades.

O desenvolvimento foi organizado em três sprints, contemplando autenticação e segurança, gerenciamento de desafios, candidaturas, submissões, inteligência artificial, portfólio e entrevistas simuladas.

## 🛠️ Tecnologias utilizadas

- Java 21 e Spring Boot
- Spring Security e JWT
- Spring Data JPA e Oracle Database
- Spring AI integrado ao Google Gemini
- RabbitMQ e CloudAMQP
- Render para hospedagem da API
- Azure DevOps Boards para gerenciamento do projeto
